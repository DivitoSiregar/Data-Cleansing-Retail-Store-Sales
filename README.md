# Data-Cleansing-Retail-Store-Sales-Menggunakan-Microsoft-Excel
Proyek ini berfokus pada proses data cleansing terhadap dataset Retail Store Sales yang diperoleh dari Kaggle. Tahapan meliputi identifikasi kolom, duplikasi, inkonsistensi data, serta validasi data. Proyek ini bertujuan menghasilkan dataset yang lebih bersih, konsisten, dan siap digunakan untuk analisis lebih lanjut.
